# MySql-GolfCourse-Project
# Golf Course Management Database System

A relational database project designed to manage operations, bookings, memberships, and staff for a golf course. Built with MySQL, this project models complex real-world entities and enforces data integrity using robust relational schemas.

# Features
* **Member Management:** Tracks player profiles, handicap levels, and membership statuses.
* **Tee-Time Bookings:** Handles scheduling for course slots, preventing double-bookings.
* **Staff & Facility Management:** Organizes course maintenance schedules, pro shop inventory, and employee assignments.
* **Complex SQL Queries:** Utilises JOIN operations, aggregate functions, and stored procedures for reporting and billing.

##  Tech Stack
* **Database:** MySQL
* **Tools:** MySQL Workbench / Command Line
